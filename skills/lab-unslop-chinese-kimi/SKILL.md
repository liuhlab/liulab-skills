# 自然中文写作（Kimi 候选版）

按目标产出的语言选用本技能，不按用户或资料的语言判断。

1. 确认读者、用途和文体。默认使用自然、规范的简体中文；用户或项目指定繁体、地区用词或既有文体时，从其约定。自然不等于口语化。
2. 阅读 `references/natural-chinese.md`，按句意和文体选用规则。
3. 先用中文在内部整理事实、读者、用途和纲要。根据资料写作时，不增添资料没有的事实、观点或因果；只有任务允许，才重选信息或改变原有结构，否则保持材料的范围、顺序和重点。
4. 直接写中文，不经过英文草稿。保留有意义的重复、术语和作者视角，不做机械替换。
5. 只交付用户要求的内容。内部纲要、评分和检查过程不随成稿输出。
