# 欧化修改：善性西化与例句库

出自余光中《从西而不化到西而化之》。这一页管**怎么改**，也管**什么时候不该改**。
病症分类在 `ouhua-diagnosis.md`，自检办法在 `ouhua-self-check.md`。

## 判准：西而不化，还是西而化之

西化分两种。**恶性西化**是「西而不化」，生吞活剥，句法原样搬过来。**善性西化**是
「西而化之」，以至「化西为中」，借来的东西成了中文自己的。

两者的差别有时绝对，多半相对：今日的作者大半出没在三分善性七分恶性的地带。

所以判断一处西化该留该改，问一句就够：**这个说法比对应的中文说法多带来了什么？**
多带来了，就是善性，留；没有，就是翻译腔，改。

**善性西化的样品，就在上乘的翻译里。**翻译是西化的合法进口。好译文的本事是「用无曲不达
的中文去诱捕不肯就范的英文」。这一条对本 skill 尤其要紧：我们做的正是这件事。

### 正面样本

钱钟书《谈教训》：

> 上帝要惩罚人类，有时来一个荒年，有时来一次瘟疫或战争，有时产生一个道德家，抱着高尚到
> 一般人所不及的理想，更有跟他的理想成正比例的骄傲和力量。

同一个意思，按恶性西化的公式改写一遍：

> 当上帝要惩罚人类的时候，他有时会给予我们一个荒年，有时会给予我们一次瘟疫或一场战争，
> 有时甚至于还会创造出一个具有着高尚到一般人所不及的理想的道德家——这道德家同时还具有着
> 和这个理想成正比例的骄傲与力量。

两句一比，前一句的简洁简直成了格言。**注意前一句并不短。**那是一气贯串的长句，中文力有
不逮的人写不出来。所以要改的从来不是长度，是构造。

张爱玲《倾城之恋》结尾「或许他有一天还会回到她这里来，带了较优的议和条件」。
那个修饰性的结尾接得自然，译回英文就是一个介系词片语。这也是善性西化。

## 例句库

括号里的字删掉即可。这是最省事的一类，先扫这一遍。

| 类 | 例句（括号内删去） |
| --- | --- |
| 代名词作受词 | 那张唱片买了没有？买了（它了）。（它）好不好听？ |
| 同上 | 你这件新衣真漂亮，我真喜欢（它） |
| 同上 | 花莲是台湾东部的小城，（它）以海景壮美闻名 |

| 同上 | 对法西斯的暴政他（作出）强烈的抗议 |

「舅舅的双手已经丧失了它们的一部分的灵活性了」这种句子，删字救不回来，要还原：
**舅舅的双手已经有点不灵了**。

### 要重组句法的

**长形容词子句**压在名词前面，像顶大而无当的高帽子。切开，另找归宿。

| 原句 | 改句 |
| --- | --- |
| 献身于革命的壮烈大业的他，早已将生死置之度外 | 他献身于革命的壮烈大业，早已将生死置之度外 |
| 男女之间的一见钟情，是一种浪漫的最多只能维持三四年的迷恋 | 男女之间的一见钟情，是一种浪漫的迷恋，最多只能维持三四年 |

**「当…的时候」四字咒**。中文靠上下文的顺序交代先后，不靠字面的衔接。

| 原句 | 改句 |
| --- | --- |
| 当你把稿子写好了之后，立刻用挂号信寄给编辑 | 你稿子一写好，立刻用挂号信寄给编辑 |
| 你怎么能说服他放弃这件事，当他自己的太太也不能说服他的时候？ | 这件事，连他自己的太太都无法劝他放手，你又怎么劝得动他？ |

**长受词**。中文忌虎头蛇尾、尾大不掉。受词拖到句末，和动词隔得太远，就失了呼应。
**让受词紧接动词**，长的切出去。

| 原句 | 改句 |
| --- | --- |
| 我决不原谅任何事先没有得到我的同意就擅自引述我的话的人 | 任何人事先没有得到我同意就擅自引述我的话，我决不原谅 |
| 那家公司并不重视刘先生在工商界已经有了三十多年的经历的这个事实 | 刘先生在工商界已经有了三十多年的经历，这件事，那家公司并不重视 |
| 张老师最讨厌平时不用功考后求加分的学生 | 张老师最讨厌学生平时不用功，考后求加分 |

同理，「我想到一条可以一举两得的妙计」不如「我想到一条妙计，可以一举两得」。

## 两个要当心的「精密」

英文有些地方确比中文精密，但绝非处处如此，而且**精密的隔壁就住着繁琐**。

- **「最…之一」并不精密。**「最伟大的」抬到至高，「之一」又稍加低抑，究竟是四位还是七位，
  你并不知道，兜一个圈子回来并无多大不同。
- **「在一定程度上」「有一定的贡献」反而不一定。**中文本有 略有、颇有、甚有、极有、最有
  之分，一说「一定的」，全分不清了。这是丢信息，不只是文风问题。

## 一条界线

这一页讲的是一般写作。诗人本有越界的自由，文学创作不在此列。但要知道常态为何物，才谈得上
求变：不知常态而自诩求变，结果多半是献拙。
