# 欧化诊断：按词性找病根

出自余光中《中文的常态与变态》。这一页只管**诊断**：句子读着别扭，先问是哪一类词在坏事。
改法和例句库在 `ouhua-repair.md`，自检办法在 `ouhua-self-check.md`。

中文的常态是**措词简洁、句式灵活、声调铿锵**。西化本身不是病，缓慢而适度的西化难以避免，
高妙的西化还能把中文写宽。成病的是西化得太快、太甚，处处违拗常态。

## 一、名词

| 病症 | 原句 | 改句 |
| --- | --- | --- |
| 抽象名词作主词 | 他的收入的减少改变了他的生活方式 | 他因为收入减少而改变生活方式 |
| 把一件事压成名词词组 | 横贯公路的再度坍方，是今日的头条新闻 | 横贯公路再度坍方，是今日的头条新闻 |
| 同上 | 书籍的选购，只好委托你了 | 选购书籍，只好委托你了 |
| 弱动词加抽象名词，架空动词 | 校友对社会作出了重大的贡献 | 校友对社会贡献很大 |
| 同上 | 已经进行了详细的研究 | 已经详加研究 |
| 同上 | 客机失事，造成九十八人死亡 | 客机失事，死了九十八人 |
| 伪术语 性、度、型、化 | 这本小说的可读性颇高 | 这本小说好看 |
| 同上 | 他的知名度超过他父亲 | 他比父亲还有名 |
| 同上 | 这是难度很高的技巧 | 这是很难的技巧 |
| 复数「们」 | 所有的伞兵们都已着陆 | 所有的伞兵都已着陆 |
| 同上 | 人们都讨厌他 | 人人都讨厌他 |
| 「之一」蛇足 | 红楼梦是中国文学的名著之一 | 红楼梦是中国文学的名著 |
| 「最…之一」 | 李白是中国最伟大的诗人之一 | 李白是中国的大诗人 |
| 「作为…之一的」 | 作为竹林七贤之一的刘伶以嗜酒闻名 | 刘伶是竹林七贤之一，以嗜酒闻名 |
| 「一定」抹平程度 | 他在针灸上有一定的贡献 | 他在针灸上颇有贡献 |

「们」在 所有、都、一致、全厂、没有一个 之后一律多余，这些词已经表了复数；「众人们」不通。

**抽象名词什么时候可以留**：好懂、简洁、必须，三条都占才留。安全感、或然率、百分比 已经
通行；可读性、知名度 没有。

## 二、连接词

中文并列往往不用连接词：生老病死、金木水火土、柴米油盐酱醋茶。危险在于 and 的意识潜入，
让 和、与、及 包办一切，挤掉灵活的 而、并、且。

| 原句 | 改句 |
| --- | --- |
| 一年有春、夏、秋和冬四季 | 一年有春夏秋冬四季 |
| 李太太的父亲年老和常生病 | 李太太的父亲年老多病 |
| 起步更早及迈步更快 | 起步更早而迈步更快 |

「而」兼有 and 与 but 两用：学而时习之是递进，怨诽而不乱是转折。

**保留**：该用连接词的地方照用。「慢而可靠」不能写成「慢、可靠」，两项分属不同层次时也
需要「并」「且」。要删的是并列同类词之间那个多余的「和」。

## 三、介词

英文离不了介词，中文不然。扬州十日、嘉定三屠，两个词组一个介词也没有。

| 病症 | 原句 | 改句 |
| --- | --- | --- |
| 关于、有关 | 关于王教授的为人，我们已经讨论过了 | 王教授的为人，我们已经讨论过了 |
| 由于…使得 | 由于他的家境贫穷，使得他只好休学 | 他家境贫穷，只好休学 |
| 由于…所以 | 由于秦末天下大乱，所以群雄四起 | 秦末天下大乱，群雄四起 |
| 作为（表身份） | 作为一个中国人，我们怎能不爱中国 | 身为中国人，怎能不爱中国 |
| 同上 | 作为一个丈夫的他是失败的 | 他做丈夫是失败的 |
| 在…的中间、在…上 | 欢迎王教授来到我们的中间 | 欢迎王教授来 |

英文重形式上的因果，中文靠上下文不言之喻：清风徐来，水波不兴，其中有因果，却不用一个
「因为」。

## 四、副词

语尾「地」把动词降为副词，主客分明而呆板。删掉「地」，代以逗点，语气就活。

| 原句 | 改句 |
| --- | --- |
| 老师苦口婆心地劝了他半天 | 老师苦口婆心，劝了他半天 |
| 他知其不可为而为之地还是去赴了约 | 他知其不可为而为之，还是去赴了约 |
| 国父成功地推翻了满清 | 国父推翻了满清 |

「成功地」最滥：既然推翻了，就是成功了，不必重复。

## 五、形容词

一碰形容词就交给「的」，是白话文僵化的主因。

| 原句 | 改句 |
| --- | --- |
| 参差的斑驳的黑影 | 参差而斑驳的黑影 |
| 灰暗的凄冷的天空 | 灰暗而凄冷的天空 |
| 夜色的来袭、风雨的将至 | 夜色来袭、风雨将至 |
| 白色的鸭 | 白鸭 |
| 有不洁的颜色的都市的河沟 | 都市的脏河沟 |

**保留**：一个「的」该在就在。「他的书」「很难的技巧」删不得，要删的是一个名词前串起来的
第二个、第三个「的」。

**前饰与后饰**，这是本页最有用的一条。修饰语放在名词之前是前饰，之后是后饰。
**前饰句是关闭句，后饰句是开放句**：后饰可以一路加下去，虽长而不失自然；前饰以名词压底，
一长就累赘紧张。句短，前饰无妨；句长就要翻过来。

- 我见到一个长得像你兄弟说话也有点像他的陌生男人
- → 我见到一个陌生男人，长得像你兄弟，说话也有点像他

文言本来多后饰：「籍长八尺余，力能扛鼎，才气过人」。换成今日的白话，很可能写成
「项籍是一个身高八尺、力能扛鼎、同时才气过人的汉子」，高帽子就戴上了。

## 六、动词

中文动词不变时态，这一面幸而免于西化。危险有两处，一是上面说过的弱动词加抽象名词，
二是被动语气。

中文的被动句本来少而短，而且不止一个「被」字：受、遭、挨、给、教、让、任、为…所、经，
都可以。另有一类根本不用标记，拿受者作主词：机票买好了，戏看完了，稿写了一半。

| 原句 | 改句 |
| --- | --- |
| 我不会被你这句话吓倒 | 你这句话吓不倒我 |
| 他被怀疑偷东西 | 他有偷东西的嫌疑 |
| 他这意见不被人们接受 | 他这意见大家都不接受 |
| 他被升为营长 | 他升为营长 |
| 他不被准许入学 | 他未获准入学 |
| 他被选为议长 | 他当选为议长 |
| 他被指出许多错误 | 有人指出他许多错误 |

**保留**：被动句本身不是病，该改的是「被」字一统天下。「为世所笑」「曾经名师指点」
「机票买好了」都是中文自己的被动，照留；作者有意强调受事时，「他被捕了」也照留。

还有「存在」的毛病：把好端端的「有」放逐，代以貌似高雅的「存在」。

- 杜甫的诗中存在着浓厚的人民性 → 杜甫的诗中富于人民性
- 中西文化的矛盾形成了代沟的存在 → 中西文化的矛盾形成了代沟

## 收尾

变化之妙，要有常态衬托才显得出来。一旦常态不存，余下的只是乱，不是变。
