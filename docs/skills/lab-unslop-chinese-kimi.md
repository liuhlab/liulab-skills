# lab-unslop-chinese-kimi：自然中文写作、严格翻译与润色（Kimi 候选版）

目标产出含有中文自然语言时，这项 skill 会自动加载，包括中英混合和双语交付物。也可以直接调用：

```text
/lab-unslop-chinese-kimi 请将这份英文 API 文档严格翻译成简体中文。
```

它按产出语言而不是请求语言选择任务。中文原创、根据资料写中文、严格翻译和中文润色都适用；纯英文、其他非中文和纯代码任务不适用。

## 写作、翻译与润色方式

Agent 用中文整理事实和内部纲要，直接写中文，不经过英文草稿。默认使用自然、规范的简体中文；用户或项目指定繁体、地区用词、读者或文体时，从其约定。正式文体不会被改成口语。

根据资料写作时，成稿只使用资料支持的事实。只有任务允许，Agent 才重选信息或改变结构。

严格翻译先读完整来源，再按段落和意群写中文，以信、达、雅为序。可以拆句、并句和调整语序，但不遗漏细节，不增加解释，也不采用根据资料写作时的选材、概括或结构改组。事实、逻辑、文档结构、术语和作者必要的程度保留都要留在译文中。

中文润色只改授权范围内确有问题的地方；原文已经自然且符合任务要求时，完整返回原文。Agent 保留作者声音、事实、判断、责任主体、条件、范围、否定、情态、程度、引用和术语，并跟随原文的简繁、地区用词和语域。技术、日常、营销和文学内容保持各自文体，不按句长、被动式或句式清单机械改写。

成稿先只看中文检查自然度，再对照来源或任务要求核查事实、逻辑、术语和保护内容。中英混合和双语交付物只处理授权的中文自然语言，其他内容及数字、版本和技术含义不变。最终回复只含用户要求的内容，不带内部纲要、评分或检查过程。

## 参考页

`natural-chinese.md` 说明词语搭配、主谓关系、指代、量词、「了、着、过」、句式和节奏，并给出中文润色的应修改与保留样例。每项规则都有适用条件与保留情形。

`chinese-westernization.md` 整理余光中的《中文的常态与变态》《从西而不化到西而化之》《论中文之西化》，按语境给出判断、改法、例外和现代技术示例，区分「善性西化」与「恶性西化」。

`technical-chinese.md` 覆盖术语优先级、英文缩写、技术语体、程度、标点、代码与命令，以及中英混合内容保护。没有可靠译名时保留英文，同一概念全篇使用同一称呼。
