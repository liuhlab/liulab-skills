# lab-unslop-chinese-kimi：自然中文写作（Kimi 候选版）

目标产出是中文自然语言时，这项 skill 会自动加载。也可以直接调用：

```text
/lab-unslop-chinese-kimi 请根据这三条记录写一段中文操作说明。
```

它按产出语言而不是请求语言选择任务。中文原创和根据中文或英文资料写中文都适用；纯英文、其他非中文和纯代码任务不适用。

## 写作方式

Agent 先用中文整理事实、读者、用途和内部纲要，再直接写中文，不经过英文草稿。默认使用自然、规范的简体中文；用户或项目指定繁体、地区用词、读者或文体时，从其约定。正式文体不会被改成口语。

根据资料写作时，成稿只使用资料支持的事实。只有任务允许，Agent 才重选信息或改变结构。最终回复只含用户要求的内容，不带内部纲要、评分或检查过程。

## 自然中文参考

随附参考页说明词语搭配、主谓关系、指代、量词、「了、着、过」、句式和节奏。每项规则都按句意和文体适用，并给出改法、例子与保留情形，避免把自然中文变成一份词语禁令。
